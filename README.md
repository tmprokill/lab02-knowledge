# Lab 02: Knowledge Base Agent with Obsidian and ChromaDB

AI-агент з базою знань для предметної області **SmartLease** (модульний моноліт .NET 10).
Підтримує інтеграцію зі сховищем Obsidian (`kb-vault`), семантичний індекс у ChromaDB, інструменти `search_knowledge`, `read_note`, `write_note` (Human-in-the-loop), захист від непрямої ін'єкції промптів та клієнт-серверний режим Chroma.\n
